# План реализации

Текущий `agent.py` задаёт только интерфейс `Agent.act(env)` и пока возвращает
пустой план.

Предлагаемые этапы:

1. Зафиксировать baseline на предоставленном шаблоне.
2. Изучить публичные данные и ограничения среды.
3. Добавить выбор пилотов и оценку их результатов.
4. Построить и проверить финальный портфель кампаний.
5. Добавить тесты, локальные прогоны и воспроизводимый `submission.csv`.

Численные результаты и выводы добавим после совместного проведения проверок.
