# Контракт агента

- Модуль: `agent.py`.
- Точка входа: `Agent.act(env)`.
- Результат: список словарей кампаний; максимум 10 кампаний.
- Пилоты запускаются через публичный метод `env.run_pilot`.
- Доступны только публичные поля и методы среды. Скрытые данные и модель
  среды использовать нельзя.

Допустимые поля кампании и ограничения ресурсов описаны в
`PARTICIPANT_GUIDE.md` и реализованы в `environment.py` / `scoring_core.py`.
Перед сдачей план будет проверен локальным evaluator.
