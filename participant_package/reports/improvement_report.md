# Сравнение v1 и окончательной v2: измерения и ограничения

Все суммы приведены в синтетических у.е. (CU). Это результаты локального оценщика, а не гарантированная реальная выручка. Каждый запуск использует новый экземпляр агента и среды; собственный seed агента равен 42. В CSV и JSON текущая версия v2 обозначена как `new`, сохранённая предыдущая версия - как `v1`. Окончательный стандартный режим: `advanced_search=True`, balanced-риск 0.55.

## История выбора и границы независимой проверки

Первый вариант v2 и один альтернативный риск-штраф проверялись на mock-seed 0-2 и seed изменённых семейств 10-11. Расширенный поиск первоначально не показал выигрыша на трёх разработочных seed и при фиксированном posterior, поэтому его временно отключили. Последующее более широкое парное сравнение выявило заметную пользу, особенно при насыщенных звонках. Поиск восстановили до передачи свежих результатов лицу, принимавшему окончательное решение. Другие параметры не менялись; после заключительной проверки дальнейшей настройки не было.

Первые расширенные результаты сохранены в `reports/v2_advanced/`, временно упрощённые - в `reports/v2_simple/`. Таблицы `advanced_vs_simple.csv` и `advanced_vs_simple_summary.json` содержат 41 парный случай, то есть 82 результата вариантов, без свежей серии. На одинаковых данных расширенный поиск повысил средний net относительно упрощённого на 2,948.77 CU для seed 0-9, на 82,702.88 CU для seed 20-29 и на 2,021,425.61 CU в семействе насыщенных звонков. При смене знаков средняя разница составила -8,294.80 CU. Первоначальные три seed оказались недостаточными для оценки этого усложнения.

Повторные серии `mock_heldout` и `model_holdout` участвовали в сравнении режимов и теперь не являются новой независимой проверкой. Их исторические имена сохранены в артефактах, а повторное использование явно отмечено в metadata.

Для заключительной проверки выделены seed 40, 41, 43, 44, 45. Из первоначального диапазона 40-44 исключён многократно проверявшийся стандартный seed 42; вместо него добавлен 45. Это исправление состава контрольной серии, а не выбор по результатам. Результаты временно упрощённого варианта на этих seed были получены отдельно, но не использовались при выборе окончательного режима. Финальная v2 проверена после фиксации; истинная mock-модель остаётся прежней, меняются только пилотные выборки и шум.

## Seed 42 и соблюдение ограничений

На стандартном seed 42 net снизился с 928,158.79 до 431,321.12 CU, а стоимость коммуникаций - с 99,646 до 20,000 CU. Рост среднего по нескольким seed не означает улучшения на каждом seed.

Все 76 основных, 6 дополнительных и 10 заключительных измерений прошли строгие проверки harness: 1-10 допустимых непустых финальных кампаний, успешные пилоты, ограничение аудитории каждой кампании, суммарные лимиты ресурсов и время меньше 300 секунд. Во всех трёх сводках зафиксирован `advanced_search=True` и одинаковые хэши окончательных решающих модулей.

В `tests/test_v2.py` проверены точное перечисление пилотных пересечений, повторные контакты, отрицательный первый эффект, воспроизводимость при фиксированном posterior, бюджеты, совпадение кэшированного расчёта с независимым жадным перебором по клиентам и обязательный fallback с минимальным оценённым ущербом с учётом риска.

Калибровка прогноза на неизвестных реальных эффектах не доказана. Все отрицательные результаты и промежуточные варианты сохранены в артефактах.

## Воспроизведение

Из `participant_package/`:

```powershell
python -m experiments.improvement --scope full --versions both
python -m experiments.improvement --scope model_holdout --versions both
python -m experiments.improvement --scope final_holdout --versions both
python -m pytest tests/test_v2.py -q
```

Результаты отдельных запусков находятся в `improvement.csv`, `improvement_model_holdout.csv` и `improvement_final_holdout.csv`. Их сводки фиксируют фактические настройки, историю выбора, хэши стратегии, данных и моделей, ресурсы, время и соблюдение ограничений. `advanced_vs_simple.csv` и его сводка объясняют измеренное основание сохранения расширенного поиска без использования свежей серии.
