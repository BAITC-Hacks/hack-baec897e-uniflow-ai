# Каталог измерений

Все суммы — CU в локальной синтетической среде. Файлы содержат фактические
измерения; уменьшение расходов не означает гарантированной прибыли.

| Артефакт | Содержание |
|---|---|
| `data_audit.json` | Аудит неизменённых входных CSV, исключённый охват, причины, хэши |
| `improvement_report.md` | Основной читаемый отчёт текущей v2 против зафиксированной v1 |
| `improvement.csv`, `improvement_summary.json` | Mock seeds 0-9 и 20-29, шесть изменённых семейств по три seed |
| `improvement_model_holdout*` | Три дополнительные таблицы эффектов; после финального упрощения повторены |
| `improvement_final_holdout*` | Новые mock seeds 40, 41, 43, 44, 45 после окончательной фиксации политики; известный 42 исключён |
| `v2_ablation*` | Три development-seed: история, prior, адаптация, риск, один канал, дополнительный поиск |
| `benchmark.csv`, `benchmark_summary.json` | Удобная сводка seeds 0-9: исходный шаблон, фиксированная v1, адаптивные v1/v2 |
| `ablation.csv`, `ablation_summary.json` | Копия текущей v2 ablation под обязательным именем |
| `scenarios.csv`, `scenarios_summary.json` | Изменённые семейства из текущего сравнения v1/v2 |
| `publication_manifest.json` | Источники и хэши агрегированных CSV |
| `planner_benchmark.json` | Скорость кэша на одинаковом замороженном posterior v1, без времени пилотов |
| `search_objective_check.json` | Сравнение базового и расширенного поиска на двух замороженных posterior |
| `advanced_vs_simple.csv`, `advanced_vs_simple_summary.json` | Более широкое парное сравнение вариантов поиска: 41 случай, без финальных новых seed |
| `decision_trace.json` | Фактический текущий balanced/42: запросы, ответы, оценки, план, ресурсы, локальный итог |
| `delivery_verification.json` | Неизменность организаторских файлов, экспорт из чистой копии, хэш submission |
| `validation.json` | Итоговая проверка поставки, команды, тесты и ссылки на HTTP-проверку |

`v1/` — архив первой версии. `experiments/reference_v1/` — её зафиксированный
код для воспроизводимого сравнения. Исходные файлы `baseline*` также относятся
к неизменённому организаторскому шаблону.

`v2_advanced/` — первая проверка v2 с расширенным поиском; `v2_simple/` —
сравнение с отключённым расширением. На трёх development-seed и двух замороженных
состояниях разницы не было, но более широкая проверка обнаружила выигрыш поиска.
Поэтому финальный `Agent()` сохраняет расширение. Повторные прежние контрольные
seed не являются новой независимой выборкой. Решение о сохранении расширения
принято до чтения результатов отдельной финальной проверки новых seed.
Ограничения и отличия явно описаны в основном отчёте.

Старые отдельные файлы `diverse_fixed*`, `overlap_sensitivity*`,
`portfolio_refinement*`, `sensitivity*` и `conservative_check*` сохраняются как
история исследований v1; их нельзя выдавать за результаты стандартной v2.
`improvement_quick*` — development-проверки промежуточных настроек, не финальные результаты.

Из `participant_package` команда `python -m experiments.publish_reports`
обновляет агрегированные имена из готовых измерений, проверяя хэши текущего ядра.
Она не запускает оценщик. Сводки времени разных серий получены при различной
параллельной нагрузке; точное сравнение скорости планировщика вынесено отдельно.

HTTP-проверка с перезапуском и совпадением CSV: `../../backend/reports/http_final_smoke.json`.
Измерение списка из 100 запусков: `../../backend/reports/storage_benchmark.json`.
