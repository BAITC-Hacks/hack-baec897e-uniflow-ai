# Предварительный калькулятор · 23 сентября 2026

Маршрут: `/calculator`. Переходы доступны из навигации, обзора, страницы нового
подбора и справки. Версия собрана и запущена в локальном Docker на порту 8080.

## Что проверено

- `npm run lint` и `npm run build` — успешно.
- `npm run test -- --maxWorkers=1` — **144 теста**, включая **53 теста** математики
  нового калькулятора: ручная арифметика, ограничения, бесплатные контакты,
  отрицательный эффект, нулевые значения, насыщение вероятности, порог
  окупаемости, некорректные входы и переполнение.
- `npm run test:e2e -- --workers=2` с Edge — **24 сценария**, включая **7 новых**:
  мгновенный пересчёт, клавиатурное управление ползунком, ввод чисел, бюджет,
  смена группы, сравнение каналов, сброс, пустая аудитория и экран 390 px.
- `npm run test:e2e:live` на собранном Docker — **5 сценариев**. Новый сценарий
  независимо рассчитывает ожидаемую сумму по текущему API и сверяет результат
  калькулятора, цену и доступное число контактов. Запусков калькулятор не создаёт.
  Остальные сценарии проверяют реальный подбор, сохранённые отчёты и русский UI.
- Скриншоты: `calculator-desktop.png` и `calculator-mobile.png`. На телефоне
  предварительный итог остаётся в поле зрения при работе с ползунками.

## Границы оценки

Это модель одного предложения и одного контакта с человеком. Входные группы,
выручка и цены связи получены из API; вероятность перехода и изменение выручки
задаёт пользователь. Средняя выручка взвешена по размеру доступных групп.
Результат — дополнительная выручка минус связь, а не полная прибыль бизнеса.

Пилоты, пересечения и повторные контакты здесь не моделируются. Калькулятор
не выбирает целевой тариф, не меняет лимиты сервера и не передаёт предположения
в новый подбор. График показывает зависимость формулы, включая точку насыщения,
а не статистический диапазон прогноза.
