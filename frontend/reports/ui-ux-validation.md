# Проверка обновления UI/UX — 23 сентября 2026

Обновлён локальный frontend: <http://localhost:8080>. Backend и frontend здоровы
по `docker compose ps`; frontend пересобран и перезапущен отдельно.

## Результаты

| Проверка | Результат |
|---|---|
| `npm run build` | Успешная TypeScript/Vite production-сборка |
| `npm run lint` | Без ошибок и предупреждений |
| `npm run test` | 34 теста, 7 файлов, все прошли |
| Flow, guidance и responsive E2E | 11 сценариев прошли |
| Дополненные guidance и новые exploration E2E | 10 сценариев прошли; 4 проверки справки повторяются с предыдущим прогоном |
| Уникальных demo E2E | 17: основной сценарий, ошибки, адаптивность, справка, offline и таблицы |
| `npm run test:e2e:live` | 1 сценарий с настоящим API прошёл |
| `docker compose build frontend` | Успешная сборка образа |
| `docker compose up -d --no-deps --wait frontend` | Обновлённый контейнер здоров |

Браузерные проверки выполнены Playwright через установленный Microsoft Edge
(`ORBITDUO_BROWSER_CHANNEL=msedge`). Проверены ширины 1440, 1280, 768 и 390 px.
Ошибок JavaScript в проверенных основных сценариях не обнаружено. На 390 px
обзор, создание и результат не создают горизонтальной прокрутки страницы.

Реальная интеграционная проверка создала локальный запуск через интерфейс,
перезагрузила страницу, дождалась результата, проверила лимиты и карточку кампании,
скачала CSV/JSON и сравнила их побайтно с экспортом API. Результат доступен в истории.

## Что проверяют новые регрессии

- Пустой seed, заблокированная форма во время отправки, отсутствие дубликатов.
- Сохранение порядка исполнения и корректная сортировка неизвестных оценок.
- Реальный повтор экспорта после ошибки, предупреждения и неизвестные бюджеты.
- Повреждённое и недоступное хранилище demo, корректные даты и конечные числа.
- Поиск в справке, отсутствие результатов, возврат фокуса, Escape и переходы.
- Закрытие справки при browser Back и работа demo в offline-режиме.
- Поиск, фильтры, сортировка, URL, reload, сброс и пагинация обеих таблиц.
- Отсутствие пропусков и дубликатов при обходе всех групп аудитории.
