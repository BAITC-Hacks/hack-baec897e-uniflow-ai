# Проверка исключения предложений

`POST /api/v1/runs/{run_id}/what-if` — независимая учебная оценка варианта
с исключёнными финальными предложениями. Доступна для завершённого
`local_simulation` запуска. Не создаёт запуск, не меняет исходный снимок,
его прогноз, журнал или экспорт. Заголовок `Idempotency-Key` не требуется.

```json
{"excluded_campaign_ids":["campaign_1"]}
```

Массив содержит не более 10 уникальных строковых ID из `RunSnapshot.campaigns`.
Пустой массив проверяет исходный вариант. Разрешено исключить все предложения:
останутся только ранее проведённые пробные проверки; это эксперимент,
а не допустимая финальная стратегия.

Ответ `200 WhatIfResult`:

```ts
interface WhatIfTotals {
  gross_gain: number;
  net_gain: number; // дополнительная выручка минус расходы на связь
  communication_cost: number;
  total_contacts: number; // включая повторные контакты
  unique_customers: number;
  remaining_budget: number;
  remaining_contacts: number;
}
interface WhatIfResult {
  run_id: string;
  label: "local_simulation";
  excluded_campaign_ids: string[];
  retained_campaign_ids: string[]; // исходный порядок выполнения
  original: WhatIfTotals;
  alternative: WhatIfTotals;
  net_gain_difference: number; // alternative.net_gain - original.net_gain
  campaigns: { id: string; audience_count: number; communication_cost: number }[];
  valid_final_plan: boolean;
  explanation: string;
}
```

Обе колонки включают пилоты и рассчитаны одной локальной моделью.
Они не являются прогнозом агента или реальной прибылью. Сервис проверяет
актуальные хеши исходных файлов, воспроизводит сохранённые пилоты по `seed`
и `sequence`, сверяет размер выборок, стоимость и наблюдения. Затем проверяет,
что официальная оценка полного исходного плана совпадает с сохранённой.
Только после этого выбранное подмножество оценивается заново тем же scorer.
Точные ID участников пилотов остаются внутри оценщика.

Пересчёт сохраняет исходный порядок предложений, бюджет, лимит контактов
и правило лучшего эффекта на каждого уникального человека. Расходы на
повторные контакты сохраняются. Освободившиеся ресурсы могут увеличить охват
более поздних предложений. Вычитание сохранённых вкладов кампаний не используется.
Конкурсный агент не получает доступ к модели оценщика, и его код не изменён.

Ошибки используют общий `ErrorResponse`:

| HTTP | Код | Условие |
|---|---|---|
| 404 | `RUN_NOT_FOUND` | Нет такого сохранённого запуска |
| 409 | `RUN_NOT_READY` | Исходный подбор не завершён |
| 409 | `WHAT_IF_DEMO_UNAVAILABLE` | Демонстрационный пример |
| 409 | `WHAT_IF_DATASET_CHANGED` | Хеши данных отличаются от исходного запуска |
| 409 | `WHAT_IF_NOT_REPRODUCIBLE` | Пилоты или исходная оценка больше не воспроизводятся |
| 409 | `WHAT_IF_BUSY` | Другой эксперимент ещё выполняется; повторить позднее |
| 422 | `UNKNOWN_CAMPAIGN` | ID не принадлежит этому плану |
| 422 | `VALIDATION_ERROR` | Неверные типы, дубликаты, более 10 ID или лишние поля |

Вычисления выполняются вне HTTP event loop. Сервис допускает один одновременный
эксперимент и отклоняет остальные без очереди. Чтение сохранённых запусков,
экспорт и health check остаются доступны.
